# Screenshot Checklist

Captured locally:

1. `desktop-dashboard.png` - dashboard showing live/cached market data and recommendations.
2. `mobile-dashboard.png` - responsive mobile dashboard.

Capture these after wallet/deployment:

1. `prepare-execution.png` - quote, official approval, swap calldata, gas checks, wallet snapshot and simulation checklist.
2. `wallet-connected.png` - BSC wallet connected state.
3. `agent-compact-api.png` - `/api/agent/recommend/compact` response.
4. `api-evidence.png` - `/api/evidence` or dashboard evidence panel.

Do not include `.env`, API keys, or wallet private material in screenshots.
